# Инструкция редактору

Статьи теперь редактируются через стандартную Django Admin. Прежние аккаунты самописной CMS здесь не действуют. Доступ выдаёт администратор; общего пароля в коде нет.

## Вход

При локальной работе откройте `START-SITE.cmd` и перейдите на http://127.0.0.1:8345/admin/. На внешнем сервере адрес выдаёт администратор после отдельного размещения. Введите свой логин и пароль, откройте раздел «Статьи». Доступны поиск и фильтры по языку и статусу. После десяти неудачных попыток входа с одного IP действует минутное ограничение.

## Новая статья

1. Нажмите «Добавить статью».
2. Заполните заголовок, язык, анонс и текст. Пустая строка разделяет абзацы. HTML не выполняется.
3. Адрес можно оставить пустым: он создастся автоматически. Для ручного адреса используйте строчные латинские буквы, цифры и дефисы. После публикации сохраняйте адрес, чтобы прежние ссылки продолжали работать.
4. Выберите обложку. Для дополнительных изображений нажмите «Добавить ещё одно изображение галереи», выберите файлы и задайте порядок. Допускаются обложка и до 12 изображений галереи.
5. Оставьте «Черновик» и нажмите «Сохранить» либо «Сохранить и продолжить редактирование».

Заголовок — до 180 символов, анонс — до 600, текст — до 100000. Изображения: PNG, JPEG, WebP, до 8 МБ каждое, до 12000 px по стороне и до 40 Мп. Повреждённые файлы, SVG и файлы с неправильным расширением не принимаются.

## Публикация и архив

Для публикации выберите English, заполните текст и установите «Опубликовано». После сохранения материал появится в `/articles/` того сервера, где открыт редактор. «Смотреть на сайте» открывает страницу статьи. Локальная публикация не обновляет GitHub Pages.

Русские статьи сохраняются как черновики или архив. Автоматического перевода нет. Для снятия с публикации выберите «Черновик», для архивирования — «Архив». Восстановление выполняется сменой статуса. Физическое удаление отключено. Дата первой публикации сохраняется.

Черновики, архив и их изображения закрыты для посетителей. Изображение, используемое также опубликованной английской статьёй, остаётся публичным через эту статью.

## Конфликт редактирования

Сервер отклоняет сохранение устаревшей версии. Ваш текст остаётся в форме с ошибкой либо на отдельном экране конфликта. Скопируйте правки, откройте актуальную статью в новой вкладке и перенесите их вручную. Не обновляйте страницу до копирования. После ошибки новые файлы потребуется выбрать снова.

При предупреждении браузера о несохранённых правках отмените переход и сохраните статью. После работы нажмите «Выйти».

## Восстановление доступа

Обратитесь к администратору. На компьютере с Django можно открыть `RESET-DEMO-PASSWORD.cmd`: он меняет пароль указанного существующего пользователя новой Django-базы. Прежние базы CMS и демо не меняются. Пароли не помещайте в переписку с кодом или в GitHub.
