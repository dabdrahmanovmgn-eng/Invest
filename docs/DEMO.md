# Локальный показ Django

Используйте `START-SITE.cmd`. Прежний `START-DEMO.cmd` также запускает локальный Django. Автоматического Cloudflare-туннеля в новом запуске нет. Старые внешние ссылки и аккаунты самописной демоверсии к нему не относятся.

Редактору — `CMS.md`, разработчику — `DJANGO.md`. Новая база находится в `data/django/`; прежние `data/demo/` и `data/cms/` сохраняются отдельно. Внешний доступ настраивается отдельным этапом после проверки конфигурации сервера.
