# Проверка Django — 04.11.2026

## Код и данные

Пройдены 26 регрессионных тестов Django: вход и CSRF, лимит попыток и недоверенные proxy-заголовки, смена пароля, права редакторов, создание/публикация/архив/восстановление, английский публичный API, закрытие черновиков и их изображений, проверка файлов и лимита галереи, конфликт версий и сохранность текста. Проверены импорт без записи, сохранение текста/дат/файлов, запрет повторной перезаписи и откат при ошибке.

`manage.py check`, `makemigrations --check --dry-run`, `pip check`, `verify_project.py`, `verify_site.py` и `verify_seo.py` завершились успешно. В полном проекте подтверждены 232 уникальных ID, 34 сохранённых табличных значения после ранее согласованных удалений и контрольные суммы трёх PDF. Новым переносом финансовые показатели не менялись.

Новая локальная база подготовлена миграциями, рабочий администратор автоматически не создавался. Прежние `data/cms/` и `data/demo/` не открывались для импорта и не изменялись. Данные для браузерного прохода созданы в изолированном тестовом хранилище и в комплект GitHub не включаются.

## Фактический браузерный проход

Проверены стандартный вход Django Admin, список статей, создание черновика и публикация через форму. Две вкладки открыли одну версию: после сохранения в первой вторая отклонила конфликт, сохранила введённый текст и показала русскую инструкцию восстановления правок. Ошибок и предупреждений JavaScript на проверенных страницах нет.

На 1280 px и 320 px проверены главная, редактор и публичная статья; горизонтального переполнения страницы нет. Публичный список показывает только английские публикации. Обложка и галерея загружены, абзацы и даты отображаются. На мобильном экране галерея загружается по мере прокрутки.

Визуальная проверка применяет Frontend Design и Web Interface Guidelines с приоритетом сохранения существующего сайта и стандартной Django Admin. Внутренние контрольные снимки хранятся отдельно от комплекта GitHub.

## Границы

В production-настройках выполнен `check --deploy`: остались два ожидаемых предупреждения о HSTS для всех поддоменов и preload-списке. Эти режимы требуют решения владельца домена и намеренно не включены. Проверка настроек не означает настройки внешнего HTTPS или готовности инфраструктуры.

Проверки проведены локально на тестовых данных. Размещение Django в интернете, работа реального HTTPS-прокси, перенос рабочих аккаунтов и статей, бизнес-приёмка не выполнялись. GitHub Pages продолжает обслуживать прежнюю статическую версию до отдельного решения о публикации. Ветка Django не включает автоматического запуска сервера или покупки инфраструктуры.
