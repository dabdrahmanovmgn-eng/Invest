# SEO-проверка — 29.10.2026

Подготовлена техническая SEO-основа для текущего адреса `https://dabdrahmanovmgn-eng.github.io/Invest/`. Новый адрес электронной почты не принят за адрес сайта: домен сайта и DNS этим поручением не менялись.

Обновление проверки 30.10.2026: EN/RU, metadata, canonical/hreflang, sitemap, контакты и ссылки прошли повторную проверку после правок контента. По решению бизнеса удалены три строки ковенантов и строка погашенного долга; 34 оставшиеся числовые ячейки таблиц и три PDF сохранены. Рост портфеля приведён к 106% в обоих местах, ТОП-5 заменён на ТОП-4. Эти изменения не являются новым финансовым расчётом или подтверждением поисковых позиций.

## Сделано

- Добавлены постоянные title и description для EN/RU, canonical, взаимные hreflang EN/RU/x-default и Open Graph. Заголовок вкладки больше не меняется при прокрутке.
- Русская версия доступна отдельным статическим файлом `index.ru.html`: текст виден без выполнения JavaScript. Переключение языка сохраняет текущий раздел и открытые блоки; адрес можно скопировать и открыть повторно.
- Добавлены `sitemap.xml` с двумя языковыми адресами и базовая разметка Organization с существующим названием компании и указанной пользователем почтой. Неподтверждённые адреса, рейтинги и юридические сведения не добавлены.
- Сохранены один H1, последовательные заголовки разделов, описания изображений, адаптивная вёрстка и ссылки на исходные PDF.
- Шрифт Manrope сжат в WOFF2: 53 756 байт вместо 164 700 байт (примерно на 67% меньше). Начертания и кириллица сохранены; `font-display: swap` и предварительная загрузка остаются.
- Редактор и пока не готовые к самостоятельной индексации страницы статей закрыты метатегом `noindex`. На статическом хостинге отсутствие API теперь показывает пустой список вместо бесконечного предложения повторять запрос.

## Проверено и ограничения

`scripts/verify_seo.py` проверяет обе статические страницы: язык, метаданные, canonical/hreflang, единственный H1, уникальность ID, существование локальных ресурсов, контакты и карту сайта. `scripts/verify_site.py` дополнительно подтверждает сохранность 41 значения таблиц и хешей трёх PDF.

Индексация и позиции в поиске не подтверждены. Search Console, реальные Core Web Vitals и Lighthouse не измерены; оценка «100/100» не заявляется. Финальная визуальная проверка и публикация отмечаются отдельно в отчёте о выполнении задачи.

GitHub Pages публикует проект в подкаталоге `/Invest/`: robots.txt из этого подкаталога не управляет обходом домена. Поэтому фиктивный рабочий robots.txt не добавлен; карта сайта готова для отправки через Search Console после подтверждения владения. При переносе на согласованный собственный домен необходимо обновить canonical, hreflang, Organization и sitemap, добавить robots.txt в корень домена и настроить перенаправления со старого адреса.

CMS требует серверного размещения; локальные демонстрационные статьи и база данных не входят в публикацию. Для SEO статей после выбора хостинга нужны серверная или статическая выдача текста по отдельным адресам, индивидуальные метаданные, корректные 404 и расширение sitemap. Необходимо снять noindex только с готовых публичных материалов. Временный внешний режим локальной CMS намеренно отправляет `X-Robots-Tag: noindex, nofollow`.

## Основания

Рекомендации Google: [отдельные адреса языковых версий](https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites), [индексация JavaScript, метаданные и предварительно сформированный HTML](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics). Эти изменения упрощают обход и понимание страниц, но не гарантируют позиции в поиске.

Пересборка RU после изменения контента: установить `scripts/requirements-build.txt`, затем выполнить `python scripts/build_locales.py`. Проверки: `python scripts/verify_site.py` и `python scripts/verify_seo.py`.
