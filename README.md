# Dengi Market — демонстрация сайта

Если не проходит вход в демоверсию, владелец компьютера может запустить `RESET-DEMO-PASSWORD.cmd`: ввести существующий демологин и дважды скрыто задать пароль от 12 символов. Меняется только пароль этого демоаккаунта; статьи сохраняются, перезапуск туннеля не нужен. Аккаунт прежней локальной CMS не переносится в демо автоматически.

В `site/` находится текущий лендинг EN/RU: разделы, анимации, фотографии команды и финансовые PDF.

Версия от 30.10.2026 содержит обновлённый дизайн, исправления мобильной сетки и анимаций, контакт IR и согласованные изменения контента: Internal Rating, рост портфеля 106%, ТОП-4, удаление отдельной таблицы ковенантов и строки Total repaid to date. Проверены EN/RU на ширинах 320–3840 px, прямые ссылки и режим без JavaScript.

## Сборка языковой версии и SEO

Главная EN — `site/index.html`, RU — автоматически собранный `site/index.ru.html`. Словарь — `site/assets/content.js`, контакты команды — `site/assets/config.js`. После изменения разметки или словаря выполните:

```sh
python -m pip install -r scripts/requirements-build.txt
python scripts/build_locales.py
python scripts/verify_seo.py
```

Краткий отчёт: `docs/SEO-REPORT-20261029.md`. Сайт использует текущий адрес GitHub Pages в canonical и sitemap; при переезде их нужно обновить. Новый контакт IR — `investors@dengimarket-ir.com`.

## GitHub Pages

В настройках репозитория **Settings → Pages → Source** выберите **GitHub Actions**. Workflow `.github/workflows/pages.yml` публикует только папку `site/` при изменении ветки `main` или ручном запуске. После успешного размещения адрес страницы: https://dabdrahmanovmgn-eng.github.io/Invest/.

GitHub Pages обслуживает статические файлы. На нём работают лендинг, навигация, EN/RU и анимации (с учётом настройки уменьшения движения браузера). Серверная админка и загрузка статей через API на Pages не работают.

## Админка и пробные статьи

Для Windows x64 с Python 3.9+ запустите `START-DEMO.cmd`. Создайте отдельный тестовый аккаунт в открывшейся локальной админке. Временная внешняя ссылка включается только после явного подтверждения в окне запуска. Тогда руководство сможет войти в демо-админку и попробовать статьи с картинками. Компьютер и окно запуска должны оставаться включёнными; остановка — Ctrl+C.

Эта CMS запускается отдельно от GitHub Pages. Тестовые данные находятся на компьютере владельца в `data/demo/`; они не отправляются в GitHub. Сессии демо и рабочей локальной CMS разделены. Установщик туннеля скачивает официальный Cloudflare cloudflared после подтверждения и проверяет SHA-256. Логин и пароль передавайте участникам отдельно от ссылки.

Для локального просмотра без внешнего доступа:

```sh
python scripts/start_demo.py --prepare-only
```

Для локального запуска рабочей CMS:

```sh
python scripts/serve_cms.py --port 8345
```

В комплекте нет аккаунтов, паролей, базы данных, загруженных статей, внутренних документов и рабочих архивов. Не добавляйте `data/` или `work/` в репозиторий.
